
# Capítulo 1.

## Prácticas sobre la instalación y configuración inicial de Oracle Database 19c

Este conjunto de prácticas tiene como objetivo preparar el entorno base para trabajar con Oracle Database 19c, desde la instalación del software hasta la verificación de la conectividad de la base de datos multitenant.
Cada práctica se desarrolla de forma secuencial y guiada, permitiendo al participante comprender los pasos esenciales para instalar, crear y validar una instancia funcional de Oracle.
