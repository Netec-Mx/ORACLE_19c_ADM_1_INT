
# **Capítulo 4** Recuperación de la Base de Datos 

En este capítulo se abordan las **estrategias y herramientas de recuperación de datos en Oracle 19c**, orientadas a garantizar la continuidad operativa de las bases de datos ante fallos físicos, errores lógicos o pérdidas accidentales de información.

A través de las prácticas, el participante aprenderá a **realizar respaldos y restauraciones utilizando RMAN**, a **recuperar información mediante las tecnologías Flashback**, y a **duplicar bases de datos activas para entornos de prueba o desarrollo**.
