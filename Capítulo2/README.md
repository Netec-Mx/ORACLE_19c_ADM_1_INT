
# Capítulo 2. Actualización de la Base de Datos

## Práctica 2.1. Upgrade de una base de datos Oracle 12c a la versión 19c


Hay camino directo a 19c desde 11.2.0.4, 12.1.0.2, 12.2.0.1 y 18c. Si vienes de 12c, normalmente puedes ir directo. (Si alguien está en versiones más viejas, se sube primero a una de estas y luego a 19c).
