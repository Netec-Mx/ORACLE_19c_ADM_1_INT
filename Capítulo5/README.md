

# **Capítulo 5.** Monitoreo y ajuste del rendimiento

En este capítulo, aprenderás a monitorear, diagnosticar y optimizar el rendimiento de una base de datos Oracle 19c, utilizando herramientas automáticas como AWR, ADDM y SQL Tuning Advisor, así como técnicas de gestión de memoria (AMM/ASMM). Realizarás prácticas que te permitirán identificar cuellos de botella, analizar cargas de trabajo, aplicar recomendaciones de ajuste y mantener un desempeño estable y eficiente en la instancia de base de datos.
